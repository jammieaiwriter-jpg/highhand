## 4. 寫入正本的鐵則（任何 bot 都適用）

1. 一律透過工具箱 `python tools/h93_tools.py`（snapshot→find 查重→變更單→apply）。工具會：寫前重抓基準、帶分頁版本號防並行覆寫、寫後重新下載驗證、自動記「異動紀錄」。**不要自己寫腳本整頁覆寫。**
2. 新增列前必查重；一個事實只住一個分頁；同廠商同日出工只留一列。
3. 有證據就結案／改日期（原值進備註）；沒證據只標記不刪；**只有里程碑、費用歸屬、公司決策三類才開「待確認」題**。
4. 里程碑（拆架／門禁／拆圍籬／消檢／使照）**絕不直接改**，只開🔴題等玲嬅回覆。
5. 日期寫前置 0 民國字串 `0115/11/12`。
6. 每筆變更記「異動紀錄」，來源尾加班次編號（雲端 `[C日期-時分]`）。
7. 推 Telegram 一個班次最多一則；Telegram 金鑰只放 routine 提示／GitHub Secrets／本機 config，**不進 repo**。

- **Claude 雲端 routine**（claude.ai/code/routines，環境 `env_018SzKjz9HEpkDKh7ikLyLBW`）：記帳 `trig_01J7knobA7jTxS94FXFEaWBz`、早班 `trig_01JJLVMzEiDn5J38mVtLktqF`、晚班 `trig_01DTxpjmaxdpMkBHuWsmmSDg`、週三會議 `trig_01PsaqoAeakzK6uPzrKLdScG`。提示正本在本機 `進度追蹤/cloud_ledger_prompt.md`、`cloud_meeting_prompt.md`。
- **GitHub Actions**（本 repo `.github/workflows/h93-cloud.yml`）：不用 LLM 的定時工作。需要 repo Secrets `H93_TG_TOKEN`、`H93_TG_CHAT`（沒設時體檢照跑但不推播）。
- **Apps Script**（drivehighhand4 名下，原始碼正本在本機 `進度追蹤/工地回報後端AppsScript.gs`）：Telegram 收發、Sheet API、版本鎖。
- **Grok**：即時對話助手。只讀正本與 plan.json；只寫回報 Sheet「TG轉送」與「廠商對照」別名。發現正本有錯 → 寫進「TG轉送」由記帳班次處理，不自己改。
- **Claude 本機 session**：玲嬅在電腦前臨時要求（處理回報、整理會勘、改程式、部署後端）。照本機 AGENTS.md。

## 6. 備援接手：什麼壞了怎麼辦

| 症狀 | 先查 | 接手做法 |
|---|---|---|
| 儀表板頁首時間戳超過 2 小時沒更新（07–22 點） | GitHub → Actions → h93-cloud 最近一次紅叉的 log | 手動 Run workflow；或任何有 repo 權限的環境執行 `pip install openpyxl && python tools/h93_tools.py rebuild` |
| 早上沒收到「🗂 雲端記帳」且有回報 | claude.ai routines 記帳 routine 的 run log | 手動 run 該 routine；或 Claude 本機 session 說「處理回報」 |
| 週三會議沒收到「📋」通知 | ①PDF 有沒有進 Drive（`?meetings=1`）②routine run log | PDF 沒進→重傳給 bot；routine 壞→手動 run；都不行→本機 session「更新會議紀錄」 |
| 早上沒收到體檢推播 | 正常（只有異常或週一才推）；確認 Actions 有跑 | 手動 Run workflow 選 audit |
| Telegram 傳了沒回「📨已收錄」 | Apps Script 觸發條件頁 tgPoll | 重建觸發器（執行 `setupTgPoll`） |
| 雲端整條都掛（Anthropic／GitHub 長時間故障） | — | 桌機工作排程器把停用的 93H_* 排程「啟用」 |
| 寫入回 `rejected_stale` | 有人同時在寫 | 重新 snapshot 後重做該分頁，不要強寫 |

## 7. 改程式的流程

- 儀表板產生器正本＝本機 `進度追蹤/建立93H儀表板.py`；工具箱正本＝`進度追蹤/h93_tools.py`；規則正本＝`進度追蹤/自動結案規則.md`。
- 改完在桌機雙擊 `自動產出上傳儀表板.bat`（會把三份同步進 repo `tools/` 並 push；排程已停用但 bat 可手動跑。另一支「產出並上傳儀表板.bat」不會同步 tools，改程式後別用它），雲端所有班次下一次就跟上。**不要直接改 repo 裡的 tools/builder.py**（會被下次同步蓋掉）。
- 改 routine 提示：改本機提示正本 → RemoteTrigger update 重送完整 job_config。
